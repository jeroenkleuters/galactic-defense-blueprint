# Galactic Defense Blueprint

Produce a clear, detailed prototype specification for a tower defense game inspired by Star Wars and space in general. Provide a complete design brief suitable for a small development team, including:
- Game concept and core loop
- Theme and visual style guidance (space/Star Wars vibe) with placeholder art notes
- Core gameplay elements: towers, enemies, paths, weapons, abilities, resources, and progression
- Levels or wave system, balance goals, and win/lose conditions
- UI layout and player feedback (HUD, controls, scoring, upgrades)
- Enemy and tower stats, upgrade trees, and tech tree concepts
- Sound and music direction (placeholder cues)
- MVP scope (what to implement first), milestones, and deliverables
- Suggested tech stack and toolchain (e.g., engine, languages, assets workflow) with minimal starter code or pseudocode sketches
- Data structures and simple algorithms for waves, targeting, and pathfinding
- Accessibility and performance notes
Provide a compact starter blueprint you could hand to a small team to begin a playable prototype in 2–4 weeks, including sample placeholder assets descriptions and a brief implementation plan.
